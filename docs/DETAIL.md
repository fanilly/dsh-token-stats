# Token 用量统计

在「设置」里增加一个「Token 用量」页签，汇总本机会话的 token 消耗和预估费用。

## 看什么

- **今日 / 区间卡片**：成本、请求数、Token、缓存命中。默认按今天统计；选择日期范围后标签从「今日」变为「区间」。
- **使用趋势**：按筛选范围自动切换：
  - 单日 → 按小时柱状图（最近 31 天有小时级数据）；
  - 2 ~ 15 天 → 按日柱状图 + 金额折线；
  - 超过 15 天或「全部日期」→ 用量热力图。左侧周几固定，右侧月份和格子可横向滚动；「全部日期」默认只展示今天往前约 30 周的一屏（无滚动），只有数据更早时才扩展到最早数据并允许滚动；没有数据的日期用浅色空格。
- **列表**：按日 / 按会话两个页签；支持目录筛选和日期筛选；父会话显示自身 + 子代理合计；分页显示总条数、页码、每页条数（10/20/50/100）和跳页。
- **悬浮明细**：柱状图和热力图 hover 时显示日期（或小时）+ Token 总量、缓存命中率、未缓存输入、缓存读取、输出、预估金额。

## 数字口径

总数与 composer 的用量 pill 完全一致：

```
totalTokens = 未缓存输入 + 缓存读取 + 缓存写入 + 输出
```

- 数据来自本地会话日志里 provider 上报的 `assistant/message` / `assistant/attempt` usage。
- 同一 `(turn, step)` 的重试按 DSH 投影语义折叠：后一次替换前一次；`llm/retry-started` 之后的下一次尝试算新增。
- 子代理是独立会话，父会话行显示「自身」和「含子代理」的合计。
- fork / 分叉会话只统计 `inheritedEventCount` 之后的自有事件，避免重复。
- 日期按事件发生时间（浏览器时区）归日；归档会话计入，零用量会话不计入。

## 预估费用

- 币种人民币（CNY），单价单位：元 / 百万 tokens。
- DeepSeek 模型按官方高峰 / 闲时价：北京时间周一至周五 9:00–12:00、14:00–18:00 为高峰，其余为闲时；周末和配置的节假日按闲时。
- 其他模型使用统一价（缓存命中 / 未命中 / 输出各一个价）。
- 内置 DeepSeek 官方在售模型的当前价格；其他模型可以在「定价设置」里添加。
- 单价保存在插件目录的 `prices.json`（首次保存时生成，已被 `.gitignore` 忽略）。
- 金额是**按列表价的估算**，不是账单。

## 性能

- 打开页签时按需聚合；会话日志按持久化 revision 缓存，只重新读取变化的会话。
- 整份结果有 15 秒短缓存，「刷新」按钮跳过。
- 小时级数据只发布最近 31 天；更早的单日会退回按日显示。

## 隐私

- 纯本地读取 `~/.dsh/sessions`，不访问外网，不上传数据。
- 不写入或修改会话日志，只读取。
- 数据接口由 DSH 本机 web server 提供（桌面版通过应用协议转发）。

## 限制

- 金额是估算，账户优惠、赠送额度、汇率、四舍五入等会让实际扣费不同。
- 价格表和节假日需要按需手动维护。
- 依赖 DSH 的 `sessionQuery` 与 `webServer` 服务。
